How it works

  1. The game picks a fixed set of songs. Squares on the cards are built from that set: every square matches 3–5 of the songs that will be played, so there's never a “Z” with only one possible song.
  2. Each card gets the same mix of square types (artist letter, title letter, year range, genre, bonus).
  3. Rule for players: each song may mark only one square on your card. This keeps the game going long enough for three rounds: one line → two lines → full card.
  4. Claims are checked in tab 5: the app checks the squares can be covered by different songs that were really played.
